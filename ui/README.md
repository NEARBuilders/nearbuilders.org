# ui

UI package for the app shell, routes, and client runtime.

## Runtime Surface

The package runtime lives in `everything-dev/ui`:

| Export | Purpose |
|--------|---------|
| `everything-dev/ui/client` | Browser router/runtime factory |
| `everything-dev/ui/server` | SSR router/runtime factory |
| `everything-dev/ui/types` | Shared router and head types |

The app-level barrel is `ui/src/app.ts` and is the preferred import for route code.

**Shared dependencies** (Module Federation singletons provided by the platform):

- `react`, `react-dom`
- `@tanstack/react-query`, `@tanstack/react-router`
- `near-kit`
- `better-auth`, `better-near-auth`

## Development

```bash
pnpm run dev       # Typical: remote host, local UI, API and plugins
pnpm run dev:ui    # Isolate UI work against the remote API
```

## Configuration

The UI is declared in `bos.app.ts` (`ui.path`). The `every-plugin` CLI synthesizes the rsbuild config, so the UI ships no `rsbuild.config.ts`. `ui/src/router.tsx` is the authored router seam (`createQueryClient`, `createRouter`); `hydrate.gen.tsx` and `router.server.gen.tsx` are generated by `bos types gen`.

## Route Protection

File-based routing with auth guards via TanStack Router:

- `_public.tsx` - Public mount with the site shell
- `_authenticated.tsx` - Requires login, redirects to `/login`
- `_admin.tsx` - Requires the admin role

All three mounts render the shared `SiteShell` from `ui/src/components/site-shell.tsx`.

## Tech Stack

- **Framework**: React 19
- **Routing**: TanStack Router (file-based)
- **Data**: TanStack Query + oRPC client
- **Styling**: Tailwind CSS v4 + shadcn/ui
- **Build**: Rsbuild + Module Federation (config synthesized by `every-plugin`)
- **Auth**: better-auth client
